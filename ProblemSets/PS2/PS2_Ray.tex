\section*{Main Tools of a Data Scientist}

\begin{itemize}
    \item Measurement - Understanding what data captures and doesn't capture; quantifying qualitative phenomena
    
    \item Statistical Programming Languages such as R (with tidyverse), Python, Julia, Stata, SAS, SPSS and Matlab

    \item Visualization Tools using ggplot2 (R), matplotlib (Python), Plots.jl (Julia) and Tableau

    \item Web Scraping using APIs (Application Program Interfaces) and HTML parsing (rvest, BeautifulSoup, Gumbo.jl)

    \item Big Data Management using SQL (Structured Query Language), Spark, Hadoop and RDD (Resilient Distributed Datasets)
    
    \item Statistical Modeling - This involves testing theories with data and explaining their behavior. 

\end{itemize}
